# 🚢 Titanic AI Platform

An Enterprise-grade Machine Learning web application built using **Python**, **Streamlit**, **Scikit-Learn**, and **Plotly** to predict Titanic passenger survival and provide interactive analytics through a modern dashboard.

---

## 📌 Project Overview

Titanic AI Platform is a complete end-to-end Machine Learning project that includes:

- Interactive Dashboard
- Data Analytics
- Dataset Explorer
- AI Survival Prediction
- Machine Learning Model
- Interactive Charts
- Professional Dark UI
- Prediction History
- Downloadable Reports

The application demonstrates the complete ML workflow from data exploration to deployment.

# 💻 Installation

Clone the repository

```bash
git clone https://github.com/anushagtalwar74-pixel/Titanic-Survival-Prediction.git
```

Open project

```bash
cd Titanic-Survival-Prediction
```

Install requirements

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run run.py
```
